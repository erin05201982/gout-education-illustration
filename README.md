# 痛風衛教網站 v1

這是一個可直接放到 GitHub Pages 的靜態網站。

## 使用方式
1. 建立 GitHub repository。
2. 將本資料夾內的 `index.html` 與 `assets` 資料夾上傳到 repository 根目錄。
3. 在 GitHub：Settings → Pages。
4. Build and deployment 選擇 `Deploy from a branch`。
5. Branch 選 `main`，folder 選 `/ (root)`，按 Save。
6. 等待數分鐘後，GitHub 會提供公開網址。
7. 用 iPhone 與 Android 各測試一次「聽醫師說」。

## 正式上線前建議
- 再確認院內核可衛教文字。
- 若需要更穩定的語音，建議之後改成預錄 MP3，而非只依賴手機文字轉語音。
- 公開網址確認後，再產生最終 QR code，避免日後重印。
